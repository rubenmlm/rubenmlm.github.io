# Práctica 2.2 - Diseño Web Responsive (RUTA 9)

* **Autor:** Rubén Martín-Luengo Martín
* **Asignatura:** Desarrollo de Interfaces Web (DIW)
* **Práctica:** P3.1 Proyecto final responsive Sass

## Descripción de la práctica
Desarrollo de la interfaz web responsive para el catálogo de motos de enduro RUTA 9, partiendo del sistema de diseño y variables creadas en Figma. El proyecto está estructurado de forma modular con SASS/SCSS (variables, mixins, mapa de breakpoints y parciales) y empaquetado con Vite para su despliegue en GitHub Pages.

## Instrucciones de ejecución

1. Requisitos previos

Tener instalado Node.js (versión 18 o superior) junto con npm.

2. Descarga y preparación del proyecto

Desde el archivo .zip entregado: descomprimir el archivo y abrir una terminal en la carpeta raíz del proyecto (donde se encuentra el archivo package.json).

Desde el repositorio de GitHub:

git clone https://github.com/rubenmlm/nombre-de-tu-repositorio.git
cd nombre-de-tu-repositorio


3. Instalación de dependencias

Como la carpeta node_modules no se incluye en la entrega, es necesario instalar Vite y Sass antes de arrancar el proyecto:

npm install


4. Ejecución en modo desarrollo

Acceder a la carpeta

cd Proyecto-Responsive


Inicia el servidor local de Vite con recarga en caliente:

npm run dev

Una vez arrancado, abre en el navegador la dirección que muestra la terminal (por defecto http://localhost:5173).

5. Compilación para producción y previsualización

Para compilar los archivos SASS y generar la versión final optimizada dentro de la carpeta docs/:

npm run build


Si deseas comprobar en local cómo queda esa versión ya compilada antes de subirla:

npm run preview


Esto levantará un servidor de vista previa (habitualmente en http://localhost:4173) sirviendo directamente el contenido de docs/.
